## 가칭: MarketingPilot (마케팅파일럿)
### Version 1.0 | 2026.03

# 1. 제품 비전 & 개요

## 1-1. 한 줄 정의
> "스타트업 대표가 URL과 5가지 질문에 답하면, AI가 마케팅 전체를 진단하고 실행까지 자동으로 해주는 올인원 마케팅 자동화 SaaS"

## 1-2. 풀어 쓴 비전
좋은 서비스를 만들었지만 마케팅 예산이 없는 스타트업에게, 월 300만원짜리 마케팅 에이전시의 핵심 가치를 월 10-30만원에 AI 자동화로 제공한다. "진단 → 전략 → 실행 → 모니터링 → 리포팅" 풀 파이프라인을 원스톱으로.

## 1-3. 핵심 원칙
- **Zero Learning Curve**: 마케팅을 모르는 대표도 URL만 넣으면 시작할 수 있어야 함
- **AI Does, Human Decides**: AI가 실행의 80%를 자동 처리, 인간은 승인/선택만
- **Show Don't Tell**: "이렇게 하세요" (교육) 가 아니라 "해놨습니다, 확인하세요" (실행)
- **Measurable from Day 1**: 첫날부터 점수와 변화가 보여야 함

## 1-4. Not Doing (만들지 않을 것)
- ❌ 범용 마케팅 자동화 (HubSpot, Mailchimp 대체 시도 안 함)
- ❌ 광고 집행 대행 (Google Ads, Meta Ads 직접 운영 안 함)
- ❌ SNS 콘텐츠 자동 포스팅 (Buffer, Hootsuite 영역 침범 안 함)
- ❌ 디자인/크리에이티브 제작 (Canva 영역 안 함)
- ❌ CRM 기능 (고객 관계 관리는 외부 도구 연동)
- ❌ 대기업/엔터프라이즈 대응 (SMB/스타트업만 집중)

# 2. 타겟 고객 (ICP)

## 2-1. 프라이머리 페르소나

**이름**: 김대표 (32세, B2B SaaS 스타트업 CEO)
- 팀 규모: 3-10명
- 마케팅 담당: 본인 겸임 또는 주니어 1명
- 마케팅 예산: 월 0-100만원
- 기술 수준: 구글 시트 가능, 코딩 불가
- 핵심 고통: "제품은 좋은데 아무도 모른다. SEO가 중요한 건 아는데 뭘 어떻게 해야 할지 모르겠다."
- 마케팅에 쓸 수 있는 시간: 주 2-5시간
- 돈 낼 의향: 효과가 보이면 월 10-30만원 가능

## 2-2. 세컨더리 페르소나

**이름**: 박마케터 (28세, 스타트업 주니어 마케터)
- 마케팅 경력 1-3년, 콘텐츠 위주
- SEO 기초는 알지만 기술적 SEO/GEO는 모름
- 에이전시를 쓸 예산 결재를 못 받음
- 도구를 써서 직접 하고 싶지만 뭘 써야 할지 모름

## 2-3. 타겟 산업
- B2B SaaS / IT 서비스
- D2C 커머스 (자사몰 운영)
- 전문 서비스 (컨설팅, 디자인, 개발 에이전시)
- 교육/EdTech
- 헬스케어/웰니스 스타트업

## 2-4. 타겟 제외
- 오프라인 중심 사업 (웹사이트 없는 사업)
- 대기업/중견기업 (월 500만원+ 에이전시 여력 있는 곳)
- 1인 프리랜서 (마케팅 자동화보다 개인 브랜딩이 먼저)

# 3. 문제 정의 (Problem Statement)

## 3-1. 핵심 문제 3가지

| # | 문제 | 기존 대안 | 대안의 한계 |
|---|------|----------|-----------|
| P1 | "마케팅을 해야 하는 건 아는데 뭐부터 해야 할지 모르겠다" | 블로그/유튜브 검색, 무료 강의 | 정보 파편화, 내 상황에 맞는 액션 불명확 |
| P2 | "에이전시 쓰기엔 비싸고, 직접 하기엔 시간/역량 부족" | 프리랜서 고용, 지인 부탁 | 품질 불안정, 관리 비용, 일관성 없음 |
| P3 | "SEO/GEO가 중요하다는데 기술적으로 어떻게 하는 건지 모르겠다" | Semrush/Ahrefs 무료 체험 | 영어 기반, 학습 곡선 높음, 진단만 하고 실행 안 해줌 |

## 3-2. 이 문제가 돈이 되는 이유

- 한국 스타트업 약 3만개+ (2024 기준 신생 법인 수)
- 이 중 70%+가 마케팅 전담 인력 없음
- SEO/GEO 에이전시 최소 월 200-300만원 → 초기 스타트업 접근 불가
- "진단은 해주지만 실행은 안 해주는" 도구만 존재 → 실행 갭

# 5. 모듈별 상세 기능 명세

## MODULE 1: 온보딩 & 데이터 수집

### 목적
고객사의 비즈니스를 AI가 이해할 수 있도록 최소한의 정보를 수집한다.
**핵심 원칙: 5분 안에 완료 가능해야 한다.**

### 5-1-1. 자동 수집 (고객 액션 불필요)

| 수집 항목 | 방법 | 수집 데이터 |
|----------|------|-----------|
| 웹사이트 전체 구조 | URL 입력 → 자동 크롤링 | 페이지 수, URL 구조, 사이트맵, 내부 링크 |
| 메타 데이터 | 크롤링 | Title, Description, H1-H6, OG 태그 |
| 기술 스택 | Wappalyzer 방식 감지 | CMS, 프레임워크, 분석 도구, 마케팅 도구 |
| 페이지 속도 | Lighthouse API | LCP, CLS, FID, 모바일/데스크탑 점수 |
| 구조화 데이터 현황 | Schema.org 파싱 | 적용된 Schema 타입, 커버리지, 오류 |
| SSL/보안 | 자동 체크 | HTTPS 여부, 인증서 상태 |
| 소셜 미디어 링크 | 크롤링에서 추출 | 연결된 소셜 계정 목록 |
| 경쟁사 추정 | AI 분석 | 동일 키워드 상위 경쟁 사이트 5개 자동 식별 |

### 5-1-2. 간편 설문 (고객 5분 투입)

**Step 1: 기본 정보 (1분)**
- 회사명
- 업종 선택 (드롭다운: SaaS / 커머스 / 서비스 / 교육 / 기타)
- 주요 제품/서비스 한 줄 설명 (텍스트)
- 웹사이트 URL (자동 크롤링 트리거)

**Step 2: 고객 & 시장 (2분)**
- 타겟 고객은 누구인가요? (B2B/B2C 선택 + 자유 텍스트 1줄)
- 고객이 우리를 찾을 때 검색할 만한 키워드 3개 (자유 텍스트)
- 주요 경쟁사 URL 1-3개 (선택사항, 없으면 AI가 자동 식별)

**Step 3: 현재 마케팅 상태 (2분)**
- 현재 마케팅 활동 (다중 선택: SEO / 블로그 / SNS / 유료광고 / 이메일 / PR / 안 하고 있음)
- 월 마케팅 예산 (선택: 0원 / ~50만원 / ~100만원 / ~300만원 / 300만원+)
- 마케팅 담당자 (선택: 대표 직접 / 담당자 1명 / 팀 있음)
- 가장 시급한 마케팅 고민 1가지 (자유 텍스트, 선택)

### 5-1-3. 계정 연동 (선택, 추후 유도)

온보딩 완료 후 대시보드에서 점진적으로 유도:
- Google Search Console 연동 (OAuth)
- Google Analytics 4 연동 (OAuth)
- 네이버 서치어드바이저 연동
- 소셜 미디어 계정 연동 (인사이트 접근)

**연동 없이도 기본 서비스 100% 이용 가능해야 함.** 연동은 "더 정확한 데이터를 위한 보너스"로 포지셔닝.

### 5-1-4. 온보딩 플로우 UX

```
[랜딩 페이지: "무료 마케팅 진단 시작"]
    ↓ CTA 클릭
[회원가입: 이메일 + 비밀번호 (또는 구글 로그인)]
    ↓
[Step 1: URL 입력] ← 입력 즉시 크롤링 시작 (로딩 애니메이션)
    ↓
[Step 2-3: 간편 설문] ← 크롤링이 백그라운드에서 진행
    ↓
[완료: "분석 중입니다... 약 2분 소요"]
    ↓
[이메일 알림: "진단 완료! 결과를 확인하세요"]
    ↓
[대시보드: 첫 번째 진단 리포트 확인]
```

**핵심 UX 설계:**
- URL 입력 → 즉시 시각적 피드백 (사이트 스크린샷 + "크롤링 중..." 프로그레스바)
- 설문 중에도 백그라운드 크롤링이 동시 진행 → 대기 시간 최소화
- 설문 완료 시 이미 크롤링 80% 완료 → 체감 속도 빠름

## MODULE 2: 진단 & 분석

### 목적
수집된 데이터를 기반으로 "마케팅 건강 점수"를 산출하고, 구체적 문제점과 기회를 식별한다.

### 5-2-1. 마케팅 종합 점수 (Marketing Health Score)

**총점 100점, 5개 카테고리:**

| 카테고리 | 배점 | 세부 항목 |
|---------|------|----------|
| **① SEO 기초 건강** | 25점 | 메타 태그 최적화, 사이트 속도, 모바일 적합성, 크롤링 오류, 사이트맵, robots.txt |
| **② 콘텐츠 품질** | 25점 | 콘텐츠 양, 키워드 커버리지, E-E-A-T 신호, 콘텐츠 신선도, 내부 링크 구조 |
| **③ GEO 준비도** | 25점 | Schema Markup 적용률, AI 봇 접근성, 즉답형 콘텐츠 비율, 엔티티 일관성, FAQ 구조화 |
| **④ 온라인 존재감** | 15점 | 소셜 미디어 활성도, 외부 언급/백링크, 디렉토리 등록, 리뷰/평판 |
| **⑤ 전환 최적화** | 10점 | CTA 명확성, 연락처 접근성, 폼 존재 여부, 리드 캡처 구조 |

**점수 등급:**
- 80-100: 🟢 우수 (미세 조정만 필요)
- 60-79: 🟡 양호 (핵심 개선점 집중하면 성장 가능)
- 40-59: 🟠 주의 (기초부터 다시 잡아야 함)
- 0-39: 🔴 위험 (온라인에서 사실상 보이지 않는 상태)

### 5-2-2. 카테고리별 세부 진단 항목

**① SEO 기초 건강 (25점)**

| 항목 | 배점 | 체크 내용 | 자동화 방법 |
|------|------|----------|-----------|
| Title 태그 | 3점 | 모든 페이지에 고유 Title 있는지, 60자 이내인지 | 크롤링 |
| Meta Description | 3점 | 모든 페이지에 고유 Description, 155자 이내 | 크롤링 |
| H1 태그 | 2점 | 페이지당 H1 1개, 키워드 포함 여부 | 크롤링 |
| 사이트 속도 | 4점 | LCP 2.5초 이내, CLS 0.1 이내 | Lighthouse API |
| 모바일 적합성 | 3점 | 반응형 여부, 모바일 속도 | Lighthouse API |
| SSL 인증서 | 2점 | HTTPS 적용 여부 | 자동 체크 |
| 사이트맵 | 2점 | sitemap.xml 존재 + 접근 가능 | 크롤링 |
| robots.txt | 2점 | 올바른 설정, 중요 페이지 차단 안 됨 | 크롤링 |
| 깨진 링크 | 2점 | 404 에러 페이지 비율 | 크롤링 |
| 이미지 최적화 | 2점 | ALT 태그, 파일 크기, 포맷 | 크롤링 |

**② 콘텐츠 품질 (25점)**

| 항목 | 배점 | 체크 내용 |
|------|------|----------|
| 콘텐츠 페이지 수 | 3점 | 블로그/리소스 페이지 최소 10개+ |
| 키워드 커버리지 | 5점 | 타겟 키워드 대비 콘텐츠 매핑 비율 |
| 콘텐츠 신선도 | 3점 | 최근 3개월 내 업데이트된 콘텐츠 비율 |
| 평균 콘텐츠 길이 | 3점 | 주요 페이지 평균 단어 수 (1,000자+) |
| 내부 링크 밀도 | 3점 | 페이지당 평균 내부 링크 수 |
| 중복 콘텐츠 | 3점 | 중복/유사 콘텐츠 비율 |
| E-E-A-T 신호 | 5점 | 저자 정보, About 페이지, 전문성 증거, 외부 인용 |

**③ GEO 준비도 (25점)**

| 항목 | 배점 | 체크 내용 |
|------|------|----------|
| Schema Markup 적용 | 5점 | Article, FAQ, HowTo, Product, LocalBusiness 등 적용 여부 |
| AI 봇 접근 허용 | 3점 | robots.txt에서 GPTBot, ClaudeBot 등 차단 여부 |
| 즉답형 콘텐츠 구조 | 5점 | 질문-답변 형태 콘텐츠 비율, 첫 문장 명확성 |
| 엔티티 일관성 | 4점 | 사이트 전체에서 브랜드/제품/서비스 명칭 통일성 |
| 사실 기반 콘텐츠 | 4점 | 통계, 출처, 인용이 포함된 콘텐츠 비율 |
| 멀티모달 요소 | 2점 | 이미지+표+도표 등 다양한 형태 활용 |
| TL;DR / 요약 블록 | 2점 | 페이지 상단 요약 존재 여부 |

**④ 온라인 존재감 (15점)**

| 항목 | 배점 | 체크 내용 |
|------|------|----------|
| 소셜 미디어 계정 존재 | 3점 | 주요 플랫폼 계정 유무 |
| 외부 백링크 | 5점 | 참조 도메인 수 (무료 API 활용) |
| 디렉토리 등록 | 3점 | 네이버 플레이스, 구글 비즈니스 등 |
| 브랜드 검색량 | 4점 | 브랜드명 월간 검색량 추정 |

**⑤ 전환 최적화 (10점)**

| 항목 | 배점 | 체크 내용 |
|------|------|----------|
| CTA 존재 | 3점 | 주요 페이지에 명확한 CTA 버튼 있는지 |
| 연락처 접근성 | 2점 | 전화/이메일/폼이 쉽게 찾아지는지 |
| 리드 캡처 폼 | 3점 | 뉴스레터, 데모 신청, 문의 폼 존재 여부 |
| 신뢰 신호 | 2점 | 고객 후기, 로고, 인증 마크 등 |

### 5-2-3. 경쟁사 자동 비교 분석

사용자가 입력한 경쟁사 URL (또는 AI가 자동 식별한 경쟁사)에 동일한 진단을 실행하여 비교표 제공:

```
내 사이트: 47점 🟠
경쟁사 A:  72점 🟡
경쟁사 B:  65점 🟡
경쟁사 C:  38점 🔴

→ "경쟁사 A는 GEO 준비도(Schema Markup)에서 당신보다 18점 앞서 있습니다.
   이 갭을 줄이려면 아래 3가지를 먼저 실행하세요."
```

### 5-2-4. AI 인사이트 생성 (Claude API)

진단 데이터를 Claude API에 전달하여 다음을 자동 생성:
- **핵심 문제 Top 3**: "지금 가장 시급한 3가지"
- **Quick Win 리스트**: "오늘 당장 고칠 수 있는 것 5가지"
- **90일 로드맵 초안**: "이 순서로 하면 점수 30점 올릴 수 있습니다"
- **예상 효과**: "이 개선을 하면 월간 유기 트래픽 ~X% 증가 예상" [확신도 표기]

## MODULE 3: 실행 & 최적화

### 목적
진단에서 발견된 문제를 AI가 직접 해결하거나, 해결을 위한 구체적 산출물을 자동 생성한다.
**"진단만 하고 끝" 이 아니라 "고쳐주는 것"이 이 제품의 핵심 차별화.**

### 5-3-1. 자동 실행 항목 (원클릭 또는 완전 자동)

| 실행 항목 | 방법 | 고객 액션 |
|----------|------|----------|
| **Schema Markup 자동 생성** | Chatsio 엔진: 페이지 분석 → JSON-LD 코드 자동 생성 | "코드 복사" 클릭 → CMS에 붙여넣기 |
| **메타 태그 최적화안 생성** | Claude API: 페이지 내용 분석 → 최적 Title/Description 제안 | "적용" 클릭 (CMS 연동 시 자동 적용) |
| **이미지 ALT 태그 제안** | AI: 이미지 컨텍스트 분석 → ALT 텍스트 자동 생성 | 복사 → 적용 |
| **내부 링크 추천** | 콘텐츠 분석 → "이 페이지에서 저 페이지로 링크 추가" 추천 | 가이드 따라 적용 |
| **robots.txt 최적화** | 현재 설정 분석 → 수정본 자동 생성 | 다운로드 → 서버 업로드 |
| **sitemap.xml 검증** | 자동 검증 + 수정 가이드 | 가이드 따라 수정 |

### 5-3-2. AI 콘텐츠 최적화 (반자동)

| 기능 | 설명 |
|------|------|
| **콘텐츠 GEO 리라이팅 가이드** | 기존 페이지를 AI 검색에 최적화된 구조로 변환하는 가이드 (즉답형 구조, FAQ 추가, 요약 블록 등) |
| **키워드 기반 콘텐츠 브리프 생성** | 타겟 키워드 → 콘텐츠 아웃라인 + 커버해야 할 토픽 + 추천 길이 자동 생성 |
| **경쟁사 콘텐츠 갭 분석** | "경쟁사는 다루는데 우리는 안 다루는 주제" 자동 식별 → 콘텐츠 제작 우선순위 리스트 |
| **FAQ 자동 생성** | 업종+키워드 기반 → "고객이 자주 묻는 질문" 10개 + 답변 초안 자동 생성 |

### 5-3-3. 실행 우선순위 시스템 (AI Task Manager)

모든 개선 항목을 "영향도 × 난이도" 매트릭스로 자동 분류:

```
[높은 영향 + 쉬움] → 🔴 즉시 실행 (Quick Win)
[높은 영향 + 어려움] → 🟡 계획 수립 후 실행
[낮은 영향 + 쉬움] → 🟢 여유 있을 때
[낮은 영향 + 어려움] → ⚪ 보류
```

대시보드에 "오늘의 할 일" 형태로 표시:
```
☐ [Quick Win] FAQ Schema Markup 추가 — 예상 효과: GEO 점수 +5점 — 소요 시간: 10분
☐ [Quick Win] 홈페이지 Meta Description 수정 — 예상 효과: CTR +15% — 소요 시간: 5분
☐ [계획 필요] 블로그 3개 GEO 구조 리라이팅 — 예상 효과: AI 인용 가능성 +30% — 소요 시간: 2시간
```

### 5-3-4. CMS별 적용 가이드 자동 생성

고객의 CMS에 맞는 적용 방법을 자동으로 제공:

| CMS | 가이드 형태 |
|-----|-----------|
| WordPress | "이 플러그인 설치 → 이 필드에 붙여넣기" 스크린샷 포함 가이드 |
| Shopify | "테마 코드 편집 → head 섹션에 붙여넣기" 단계별 가이드 |
| Cafe24 | "디자인 → HTML 편집 → 삽입" 가이드 |
| Wix | "Wix SEO Wiz → 커스텀 코드" 가이드 |
| 자체 개발 | JSON-LD 코드 + 개발자 전달용 기술 문서 |

## MODULE 5: 리포팅 & 인사이트

### 목적
고객이 "이 도구 덕분에 뭐가 좋아졌는지"를 명확히 체감하도록 한다.
리포트 자체가 "계속 구독해야 할 이유"가 되어야 한다.

### 5-5-1. 리포트 종류

| 리포트 | 주기 | 내용 |
|--------|------|------|
| **주간 스냅샷** | 매주 월요일 | 점수 변화, 주요 변동사항 3줄 요약, 이번 주 할 일 1가지 |
| **월간 마케팅 리포트** | 매월 1일 | 종합 점수 추이, 카테고리별 상세, 경쟁사 비교, AI 인용 현황, 다음 달 추천 액션 |
| **분기 전략 리뷰** | 분기말 | 3개월 성과 종합, ROI 분석 (연동 시), 다음 분기 전략 권고 |
| **온디맨드 진단** | 수시 | "지금 다시 진단" 버튼으로 실시간 재진단 |

### 5-5-2. 리포트 전달 방식

- **이메일**: 주간 스냅샷은 간단한 이메일 (3줄 요약 + 대시보드 링크)
- **대시보드**: 월간 리포트는 대시보드에서 인터랙티브하게 확인
- **PDF 다운로드**: 월간/분기 리포트는 PDF로 다운로드 가능 (대표가 투자자/이사회에 공유 가능)

### 5-5-3. AI 인사이트 자동 생성

매월 Claude API가 데이터를 분석하여 다음을 자동 생성:
- "이번 달 가장 큰 개선: ___"
- "이번 달 가장 큰 리스크: ___"
- "다음 달 집중해야 할 1가지: ___"
- "경쟁사 대비 우리가 앞선 점 / 뒤진 점"

# 6. 서비스 플로우 — 고객 여정 전체

## 6-1. 고객 라이프사이클 플로우

```
[AWARENESS] 인지
    │ 콘텐츠 마케팅 / 무료 진단 도구 / 커뮤니티 입소문
    ▼
[ACQUISITION] 획득
    │ 랜딩페이지 → 무료 진단 시작 (이메일만 필요)
    ▼
[ACTIVATION] 활성화 ← 🔴 가장 중요한 순간
    │ 첫 진단 리포트 확인 → "우리 점수 47점이네..." 충격
    │ Quick Win 1개 실행 → 점수 상승 체감
    ▼
[REVENUE] 수익화
    │ 무료 진단 후 → "더 자세한 분석 + 자동 실행" → 유료 전환
    ▼
[RETENTION] 유지
    │ 주간 리포트 → 점수 상승 추적 → "이 도구 없으면 불안"
    ▼
[REFERRAL] 추천
    │ "너네 사이트 GEO 점수 몇 점이야?" → 바이럴
```

[무료 진단 완료]

    ↓
[Quick Win 1개 무료 제공: "이거 하나만 고치면 +5점"]

    "나머지 17개 개선 항목 확인하기" → 🔒 유료

    ↓
[체험 5일차: "체험 기간 동안 점수가 12점 올랐습니다. 계속하시겠습니까?"]

# 8. 기술 스택 & 필요 항목

## 8-1. 기술 아키텍처

| 레이어 | 기술 | 용도 |

| **자동화** | n8n (self-hosted) | 크롤링 스케줄, 모니터링, 이메일 발송 |
| **크롤링** | Playwright (Headless) | 웹사이트 크롤링, JS 렌더링 페이지 처리 |
| **이메일** | Resend 또는 Postmark | 트랜잭셔널 이메일, 리포트 발송 |

|--------|------|------|----------|
| "스타트업이 월 10만원도 안 냄" | 중 | 높음 | 무료 체험 + 점수 상승 체감 후 전환. 첫 달 50% 할인 |
| "AI 진단이 부정확하면 신뢰 잃음" | 중 | 높음 | 룰 기반 항목(SSL, 사이트맵 등)으로 정확도 확보 후 AI 항목 점진 추가 |
| "Schema 적용이 어렵다고 느낌" | 높음 | 중 | CMS별 스크린샷 가이드 + "개발자에게 보내기" 원클릭 기능 |
| "Semrush/Ahrefs가 GEO 기능 강화" | 중 | 중 | 한국어 특화 + SMB 가격대 + "실행까지 해줌" 차별화 유지 |
| "API 비용이 스케일 시 급증" | 중 | 중 | 캐싱, 배치 처리, 룰 기반 우선 → AI는 최소한으로 |
| "크롤링이 차단당함" | 낮음 | 중 | Headless 브라우저 + 속도 제한 + 예의 있는 크롤링 |
