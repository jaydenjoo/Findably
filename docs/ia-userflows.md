# User Flows — Findably

> PRD v3.0 Section 7 기반
> 모든 Flow: 출발→목적 + 클릭 수 + 소요 시간

---

## F-001: 무료 진단 (핵심 Flow)

| 항목      | 내용                                                         |
| --------- | ------------------------------------------------------------ |
| 대상      | 신규 방문자 (비로그인)                                       |
| 출발      | / (랜딩)                                                     |
| 목적      | 간단 리포트 확인 (점수 + 문제 3개 + Quick Win 1개 + AI 인용) |
| 클릭 수   | 4~5 클릭                                                     |
| 소요 시간 | ~3분 (분석 대기 ~2분 포함)                                   |

```
경로:
/ (랜딩)
  → "무료 진단 시작 →" CTA 클릭
  → /signup (이메일 or 구글 가입)
  → /onboarding/url (URL 입력)
  → [선택] /onboarding/info (추가 정보)
  → /onboarding/analyzing (AnalyzingScreen, ~2분)
  → /dashboard (간단 리포트 표시)
```

### 주요 화면 상태

- `/onboarding/analyzing`: 프로그레스 게이지 + 현재 검사 항목 + 완료 체크리스트 + 카운트다운
- `/dashboard` (Free): 종합 점수 + AI 인용 + Quick Win 1개 + BlurOverlay

## F-002: 샘플 열람

| 항목      | 내용                                                  |
| --------- | ----------------------------------------------------- |
| 대상      | 비로그인 or 무료 사용자                               |
| 출발      | 대시보드 or 랜딩                                      |
| 목적      | 그린테크 풀 리포트 열람 → "나도 받고 싶다" → 결제 CTA |
| 클릭 수   | 2 클릭                                                |
| 소요 시간 | ~2분 (열람)                                           |

```
경로:
/dashboard "샘플 보기" 버튼
  → /reports/sample (그린테크 풀 리포트, 블러 없음)
  → 스크롤 열람
  → "내 사이트도 분석하기 →" CTA
  → /onboarding/url (로그인 상태) or /signup (비로그인)
```

## F-003: 유료 결제 → 상세 진단

| 항목      | 내용                                                     |
| --------- | -------------------------------------------------------- |
| 대상      | 무료 진단 완료 사용자                                    |
| 출발      | /dashboard (BlurOverlay CTA)                             |
| 목적      | 상세 리포트 확인 (60개+ 항목 + 경쟁사 + 90일 계획 + PDF) |
| 클릭 수   | 3 클릭                                                   |
| 소요 시간 | ~2분 (분석 ~1분, 결제 ~1분)                              |

```
경로:
/dashboard "상세 분석 받기 — 9.9만원" CTA
  → Toss Payments 결제 팝업 (9.9만원)
  → 결제 완료
  → /onboarding/analyzing (5-Agent 병렬 분석, ~50초)
  → /dashboard (상세 리포트 언락 — BlurOverlay 제거)
```

### 결제 실패 대응

- 결제 취소: 원래 화면으로 복귀 + 토스트 "결제가 취소되었습니다"
- 결제 실패: 에러 토스트 + "다시 시도" 버튼
- 중복 결제 방지: 결제 진행 중 버튼 비활성화

## F-004: PDF 다운로드

| 항목      | 내용              |
| --------- | ----------------- |
| 대상      | 유료 사용자       |
| 출발      | /reports/my/[id]  |
| 목적      | PDF 파일 다운로드 |
| 클릭 수   | 1 클릭            |
| 소요 시간 | ~10초 (생성 시간) |

```
경로:
/reports/my/[id]
  → "PDF 다운로드" 버튼
  → 생성 프로그레스 표시 (로딩 스피너)
  → 브라우저 다운로드 트리거
```

## F-005: 실행 도구 (Schema 코드 생성)

| 항목      | 내용                                    |
| --------- | --------------------------------------- |
| 대상      | 유료 사용자                             |
| 출발      | /dashboard Quick Win or /actions        |
| 목적      | Schema Markup 코드 복사 → 사이트에 적용 |
| 클릭 수   | 2~3 클릭                                |
| 소요 시간 | ~1분                                    |

```
경로:
/dashboard QuickWinCard "지금 고치기 →"
  → /actions/schema (자동 생성된 코드 표시)
  → CMS 감지 결과에 따라 맞춤 적용 가이드 표시
  → "코드 복사" 버튼 클릭
  → 클립보드 복사 + 토스트 "복사되었습니다"
```

## F-006: robots.txt 차단 시 대응

| 항목      | 내용                                      |
| --------- | ----------------------------------------- |
| 대상      | 크롤링 차단된 사이트 소유자               |
| 출발      | /onboarding/analyzing                     |
| 목적      | 가능한 범위로 리포트 생성 + GSC 연동 유도 |
| 클릭 수   | 0 (자동 대응)                             |
| 소요 시간 | 일반과 동일                               |

```
경로:
/onboarding/analyzing
  → 크롤링 시도 → 차단 감지
  → 대체 데이터 수집 (PageSpeed, SSL 등 ~60%)
  → /dashboard ("일부 항목이 제한되었습니다" 안내 배너)
  → [선택] GSC 연동 버튼 → Phase 2 안내
```
