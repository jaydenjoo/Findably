# Findably 유료 리포트 검수 수정 지시문 v1

> **작성일**: 2026-04-06
> **지시자**: Jayden
> **목적**: 유료 마케팅 진단 리포트의 신뢰도 문제 해결
> **타겟 고객**: 직원 10인 이하 소상공인/소기업 대표
> **핵심 기준**: 2025 Q4 소상공인 사업장당 월 평균 매출 약 1,640만원 (KCD 데이터)

---

## 🚨 근본 문제

현재 유료 리포트가 소상공인(월매출 1,640만원)에게 **월 5,638만원 누수**를 주장 → 실매출의 **3.4배 과장** → 타겟 고객이 보면 즉시 신뢰 상실.

---

## Task 1: 💧 매출 누수 추정 로직 재설계 (최우선)

### 현재 문제

- 심각 항목 일률 338만원, 주의 항목 일률 113만원 → 합산 시 월 5,638만원
- 소상공인 월매출(~1,640만원)의 3.4배 → 타겟 고객이 보면 신뢰 상실

### 수정 지시

1. **고객 규모별 기반 매출 변수 도입**
   - 리포트 생성 시 고객의 업종/규모 정보를 기반으로 `baseMonthlyRevenue` 변수 설정
   - 입력 없으면 소상공인 기본값: **월 1,640만원** 적용
   - 이 변수가 모든 비용 추정의 앵커가 됨

2. **총 누수 추정치 캡(cap) 적용**
   - 최대 누수 = `baseMonthlyRevenue × 0.20` (매출의 20%)
   - 즉 월매출 1,640만원이면 **최대 누수 추정 = 약 328만원/월**
   - 리포트에 "매출 대비 약 X% 수준의 마케팅 비효율이 추정됩니다" 표현 사용

3. **항목별 영향도 차등 가중치**
   - 각 진단 항목에 가중치(weight) 배정, **총합 = 1.0**
   - 예시 가중치 배분:

     ```
     SSL 문제:        0.15  (직접적 이탈 유발)
     LCP 속도:        0.20  (바운스율 직결)
     모바일 터치:     0.12  (한국 모바일 82% 고려)
     Schema Markup:   0.08  (간접 영향)
     내부링크:        0.06  (간접 영향)
     이미지 부재:     0.08  (신뢰도 영향)
     E-E-A-T:         0.07  (간접 영향)
     기타 항목:       나머지 배분 (= 0.24)
     ```

   - 각 항목 표시 금액 = `총 누수 캡 × 해당 항목 가중치`

4. **중복 영향 보정 명시**
   - 리포트에 다음 문구 추가:
     > "각 항목의 추정 영향은 독립적으로 합산되지 않습니다. 여러 문제가 동일한 사용자 이탈에 기여하므로, 총 누수 추정치는 개별 합산이 아닌 보정된 총합입니다."

5. **금액 표현 방식 변경**
   - 기존: "월 약 338만원 손실 추정"
   - 변경: "매출의 약 3~5% 영향 · 월 약 XX만원 추정 (월매출 X만원 기준)"
   - 반드시 기준 매출을 병기하여 추정 근거를 투명하게 공개

## Task 2: 종합 점수 불일치 해결

### 현재 문제

- 1페이지 헤더: 62점
- 2페이지 SWOT 내부: 72점
- 동일 리포트 내 점수 충돌

### 수정 지시

- 리포트 생성 로직에서 종합 점수를 **단일 변수(`overallScore`)로 관리**
- 모든 페이지에서 이 변수를 참조하여 일관된 점수 표시
- 현재 어느 점수가 정확한지 확인 후 통일
- 만약 62점 = 가중 평균, 72점 = 단순 평균이라면, 하나만 선택하고 산출 방식을 각주로 명시

## Task 3: 중복 항목 통합

### 현재 문제

같은 이슈가 카테고리만 다르게 반복 등장:

- SSL 문제 → 3회 (technical / seo / 별도)
- LCP 5.7초 → 2회 (technical / seo)
- Schema Markup → 3회 (seo / geo / technical)
- 내부링크 부재 → 2회 (technical / seo)

### 수정 지시

- 동일 근본 원인(root cause)을 가진 항목은 **하나로 통합**
- 통합된 항목에 **"영향 범위: SEO, GEO, Technical"** 태그를 복수 표시
- 통합 후 항목 수가 줄어도 OK — 유료 리포트의 가치는 항목 수가 아니라 정확성
- 통합 예시:

  ```
  기존:
    [심각] SSL 인증서 문제로 보안 경고 발생 (technical)
    [심각] SSL 인증서 문제로 신뢰도 및 SEO 점수 하락 (seo)
    [심각] 검색 결과에서 사이트 신뢰도가 떨어져 클릭률 낮음 (technical)

  통합 후:
    [심각] SSL 인증서 미유효 — 보안 경고 + SEO 순위 하락 + 클릭률 저하
    영향 범위: technical, seo
    (하나의 항목에 3가지 영향을 모두 서술)
  ```
