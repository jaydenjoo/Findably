## 1. 서비스 한 줄 요약

**"URL 하나 입력하면, AI가 마케팅 점수를 매기고 '이것부터 고치세요'라고 알려주는 서비스"**

- 병원 건강검진과 같은 구조: 접수(URL) → 검사(60개+ 항목) → 결과지(점수 + 실행 계획)

## 2. 문제 정의

### 시장 변화

```
과거: "맛집 추천" → 네이버/구글 검색 → 파란 링크 클릭
현재: "맛집 추천해줘" → ChatGPT/Perplexity → AI가 바로 답변
```

**핵심 문제:** AI가 답변할 때 "당신의 사이트"를 언급 안 하면 → 고객이 찾지 못함, 경쟁사만 추천됨.

### 타겟 고객의 고통

| 페르소나      | 프로필                            | 핵심 고통                                                     |
| ------------- | --------------------------------- | ------------------------------------------------------------- |
| 김대표 (32세) | 스타트업 CEO, 팀 5명, 마케팅=본인 | "제품은 좋은데 아무도 모른다". 에이전시 월 300만원 부담       |
| 박실장 (28세) | 주니어 마케터                     | SEO 개념은 아는데 구체적 실행법 모름. 대표에게 증명 자료 필요 |

### 중소기업이 마케팅 컨설팅에서 느끼는 불만

1. **"돈은 썼는데 뭐가 변했는지 모르겠다"** — 성과 체감 부재
2. **"리포트만 두꺼운데 뭘 해야 하는지 모르겠다"** — 실행 가능성 부재
3. **"에이전시가 전문용어만 써서 이해가 안 된다"** — 소통 단절
4. **"3개월 계약인데 중간 성과를 볼 수 없다"** — 중간 점검 불가

## 3. Findably의 해결 방법

### 핵심 차별점: SEO + GEO 통합 진단

| 기존 서비스                 | Findably                        |
| --------------------------- | ------------------------------- |
| SEO만 진단 (구글 검색)      | SEO + GEO 통합 (구글 + AI 검색) |
| 영어 중심, 한국 시장 미고려 | 한국어 전용, 한국 시장 최적화   |
| 리포트만 제공               | 리포트 + 실행 도구 + 코드 생성  |
| 월 수백만원 에이전시        | 건당 9.9만원 (1/30 가격)        |
| 전문가만 이해               | 비전문가도 이해 가능한 점수제   |

### GEO란? (Generative Engine Optimization)

> 기존 SEO가 "구글 검색에서 잘 보이는 것"이라면, GEO는 "ChatGPT, Perplexity 같은 AI가 당신을 추천하는 것"

- 2026년 현재 한국에서 "GEO"를 전문으로 다루는 서비스는 거의 없음 → **블루오션**
- 전 세계적으로 AI 검색 점유율 급성장 중 (ChatGPT 월간 활성 사용자 3억+)
- Findably는 "AI가 당신을 추천하는가?"를 실제로 측정하고 개선안까지 제시

### GEO 점수 산출 체계

| 항목             | 비중 | 설명                         |
| ---------------- | ---- | ---------------------------- |
| AI 인용 가능성   | 25%  | AI가 콘텐츠를 인용할 만한가  |
| 브랜드 신뢰 신호 | 20%  | 외부에서 브랜드 언급 빈도    |
| 콘텐츠 품질      | 20%  | 전문성, 정확성, 구조         |
| 기술 기초        | 15%  | 속도, 보안, 모바일           |
| 구조화 데이터    | 10%  | Schema Markup, JSON-LD       |
| 플랫폼 최적화    | 10%  | ChatGPT/Perplexity 각각 대응 |

## 4. 제품 구조

### 4-Layer 크롤링 엔진 (핵심 기술)

```
[입력] URL 하나만 입력
    ↓
━━ Layer 1: 직접 크롤링 ━━━━━━━━━━  비용 0원
   HTML 메타태그, H1~H6, Schema, robots.txt, sitemap,
   llms.txt, 내부링크, 이미지 ALT, 깨진링크, CMS 감지, 보안, 모바일
    ↓
━━ Layer 2: Google 무료 API 4종 ━━━  비용 0원
   PageSpeed Insights, CrUX, Safe Browsing, Search Console
    ↓
━━ Layer 3: 오픈소스 도구 ━━━━━━━━  비용 0원
   Wappalyzer, Lighthouse, Mozilla Observatory, SSL Labs
    ↓
━━ Layer 4: 유료 API (성장 후) ━━━━  사용량 비례
   Moz(MVP~), DataForSEO(100명+), Ahrefs(500명+)
    ↓
[분석] 룰 기반 점수 + AI 인사이트
    ↓
[출력] 리포트 (웹 + PDF)
```

**핵심:** Layer 1~3까지 비용 0원 → 무료 진단의 원가가 0원에 수렴

### 5-Agent AI 병렬 분석 (유료)

```
[Phase 1: 동시 검사] (~30초)
   ├─ 기술 전문가    → 속도, 보안, 모바일
   ├─ SEO 전문가     → 검색 최적화
   ├─ GEO 전문가     → AI 검색 노출 + 인용 추적
   ├─ 콘텐츠 전문가  → 글 품질, 구조, 전문성
   └─ 경쟁사 분석가  → 경쟁사 병렬 비교

[Phase 2: 결과 합치기] (~10초)
   → 점수 합산 + 우선순위 정리

[Phase 3: CMO 검증] (~10초)
   → AI 리포트 품질 확인 + 오류 필터링
```

**"5명의 전문가가 동시에 사이트를 검사하고, 마케팅 임원이 최종 검수하는 구조"**

## 5. 사용자 여정 (User Flow)

### Flow 1: 무료 진단 (핵심 — 4클릭, 약 3분)

```
랜딩페이지 방문
  → "무료 진단 시작" 클릭
  → 회원가입 (이메일 또는 구글 1클릭)
  → URL 입력 (사이트 주소 1개만)
  → AI 분석 대기 (~2분, 실시간 진행률 표시)
  → 결과: 종합 점수 + 주요 문제 3개 + 바로 고칠 수 있는 것 1개 + AI 인용 가능성
```

### Flow 2: 유료 상세 진단 (3클릭, 약 2분)

```
무료 결과 확인 → "더 자세히 보고 싶다"
  → "상세 분석 받기 — 9.9만원" 클릭
  → 결제 (토스페이먼츠)
  → 5-Agent AI 분석 (~50초)
  → 상세 리포트: 60개+ 항목 + 경쟁사 3사 비교 + 90일 실행 계획 + PDF
```

### Flow 3: 샘플 열람 (전환 유도)

```
"이런 리포트를 받을 수 있습니다" → 가상 회사 "그린테크" 풀 리포트 열람
→ "내 사이트도 분석하기" → 결제
```

## 10. ROI 증명 방법 (중소기업 체감 전략)

> "돈 쓴 만큼 효과 있는지 모르겠다" 문제를 7가지 방법으로 해결

### 방법 1: Before-After 스냅샷

- 진단 전 점수 vs 개선 후 점수 시각적 비교
- "47점 → 78점" 한 눈에 체감

### 방법 2: 2:20:200 대시보드 패턴

- **2초**: 종합 점수 (숫자 하나)
- **20초**: 카테고리별 상태 (SEO/GEO/기술/콘텐츠)
- **200초**: 상세 항목 60개+ 분석

### 방법 3: 돈으로 환산

- "이 개선을 하면 월 방문자 +200명 예상 → 전환율 적용 시 매출 +○○만원 기대"
- 추상적 점수를 구체적 금액으로 변환

### 방법 4: 경쟁사 벤치마크

- 동종 업계 3개사와 나란히 비교
- "경쟁사 A는 85점인데 우리는 47점" → 위기감 + 구체적 격차 인식

### 방법 5: 마이크로 전환 추적

- robots.txt 수정 → AI 봇 접근 허용 → AI 인용 가능성 변화 추적
- 작은 행동의 효과를 즉시 확인

### 방법 6: 실시간 알림

- "Schema Markup 적용 후 구글 리치 결과 노출 시작" 알림 (Phase 2)
- 성과를 기다리지 않고 즉시 인지

### 방법 7: 성공 시나리오 제시

- 유사 업종 사례: "같은 업종 B사는 이 개선으로 3개월 내 검색 순위 12→3위"
